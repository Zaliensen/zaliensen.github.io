Set up the activity

Try four synthetic slides immediately, or choose a PDF you have permission to use.

Tab moves between controls. On the presentation surface, Space, Enter or Right moves forward; Left goes back. Escape returns here. Sound and video are optional.

For PDFs, run python -m http.server 8080 --bind 127.0.0.1 in this folder and open http://127.0.0.1:8080. The synthetic demo also opens directly as a file.
