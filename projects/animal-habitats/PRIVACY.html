Return to Animal Habitats

Privacy and release boundary

This demo has no recovered learner records. The three learner labels are fictional controls, not pseudonyms for actual people. New neutral lesson text and code were assembled from a narrow reviewed source selection; the original roster, individual goals, notes, name bindings and media were not transformed into sample records.

The demo has no free-text identity fields, file import, microphone/camera access, analytics, exports, localStorage, sessionStorage or IndexedDB use. Its counters exist only in page memory and reset on reload. The Content Security Policy disallows network connections, media, images, objects and form submissions. Tests observed no attempted external requests. These controls do not prove all possible future changes are safe.

Do not add real names, class identifiers, individualized goals, screenshots, recordings, backup files or historical exports to the folder, Git history, issues or attachments. A local demo is not an institution-approved student-data system. No claim of FERPA/NYCPS compliance, consent or institutional publication approval is made.

Keep the private archives and detailed recovery records separate. Review the exact files, contribution history and code rights before publication. Student-data rules and the synthetic-report alternative are documented in the separately supplied student-data publication plan.
