Letter and music literacy workflows

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

This is one project family with two related content branches: Missing Music Story Studio and Letter Crew. Static comparison found 59 shared function names and 36 byte-identical function bodies, including reading, support, administration and backup helpers. They are presented together instead of as two repositories.

Package status: source references and case study, not restored full applications. The original interfaces rely on personalized learner records and embedded media. This package retains only inspected task-building functions, new adapters and invented test inputs. It contains no roster, individual goals, original audio, artwork, book pages or saved observations.

What the code demonstrates

Missing Music's options and buildTask functions create six scenes at three configured levels. The lower setting uses two-choice uppercase matching; another setting uses three-choice beginning-sound questions; the higher setting includes blending, story-detail, cause/effect and sequence questions. These are task configurations, not validated learner ability levels.

Letter Crew's selected step and buildStoryTask functions describe a broader activity sequence. For example, a drag task becomes a simple object selection at level 1, a word task adds a first-letter step at level 3, and rhythm counts vary from one to three. This is concrete evidence of adapting response demands within one classroom workflow.

missing-music-core.cjs and letter-crew-core.cjs keep those original function bodies. New wrappers replace global learner/session dependencies with explicit invented inputs and reject unsupported levels. The Letter Crew text-normalization adapter is newly written. No original application is executed by importing these modules.

Run the checks

With an existing Node.js installation:

node tests/test-core.cjs

No dependencies or network access are required. Tests passed for all 18 Missing Music scene/level combinations, the single-correct-option invariant, invalid scene rejection and Letter Crew word, drag, rhythm and multi-step adaptations. The fixtures are invented, with no original student values. These tests do not restore or validate the complete original lesson, audio timing, storage, exports or accessibility.

The code and notes demonstrate classroom workflow design and the relationship between a visible configuration and its response demands. They do not claim measured learning outcomes or sole manual coding. Original media and third-party characters are excluded. A software license has not yet been selected for this reference package.
