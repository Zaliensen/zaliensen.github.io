Country literacy quests — source-backed reference collection

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

Seven recovered activities are represented as four implementation families, with four country variants inside one reusable board-quest engine. This is a documentation/code-reference collection. It does not contain runnable original applications, learner records, media or external-resource links.

The strongest evidence here is workflow adaptation: configurable lesson paths, different answer formats, explicit turn/phase state, retries, teacher controls and reusable interaction structures. These are implemented design choices. They are not measured learning or deployment outcomes.

Portfolio grouping

Implementation family Included variants Why grouped this way
Reusable board-quest engine Japan, Egypt, China, France Shared setup, state, lessons, turns, quiz/arcade dispatch and save/summary architecture; 45–64 identical named function bodies between variant pairs.
Egypt Arcade Mission Timed six-chapter activity Different chapter schema, timer controls and six arcade engines.
Spain Detective Mission Six-chapter landmark/clue workflow View-by-view hotspots, two questions per chapter, tiles and optional panorama routes.
Japan Compass Mystery Five-scene guided mystery A one-clue guided view, discussion timer and Story/Look/Answer/Prize phases.

Egypt Quest and France Quest each contain byte-identical START/Editable HTML copies. Each pair is counted once. A shared country does not make two different interaction engines duplicate versions. The grouping is based on source structure, not filename marketing words or an assumed development chronology.

Individual source notes

  • Japan Quest — clean rebuild variant — An eight-lesson, 48-position board-quest variant with team turns, a 24-question early bank and ten declared literacy activities.
  • Egypt Quest — polished variant — An eight-lesson, 40-position board-quest variant with 24 early question records, ten literacy activities and country-specific lesson/art configuration.
  • China Quest — kindergarten literacy variant — An eight-lesson, 40-position board-quest variant with a 20-record early literacy question bank and ten declared literacy activities.
  • France Quest — ten-arcade / YouTube variant — An eight-lesson, 40-position board-quest variant with a larger arcade dispatcher and optional external song links.
  • Egypt Arcade Mission — timed six-chapter activity — A separate chapter-based activity combining timed arcade rounds, short reading passages, questions and team progress.
  • Spain Detective Mission — guided landmark exploration — A separate six-chapter clue-finding and question workflow with local views and optional online panorama destinations.
  • Japan Red Sun Compass — guided mystery variant — A five-scene guided exploration flow emphasizing one visible clue, two questions, discussion and a collected piece.

catalog.json records the selected source names/hashes, counts, function-level evidence, family decisions and exclusions. The notes describe the specified recovered variants; a filename containing “final,” “working” or “clean” does not certify correctness or global recency.

Safe code references

reference/code_reference.js.txt contains three short, generic source extracts: quick/full lesson-path selection, serpentine board coordinates and a guided phase indicator. They have no learner values, media, storage or network behavior. Source identity is recorded beside each extract. The complete source applications remain private.

node reference/test_reference.cjs runs only these reviewed extracts with synthetic fixtures. It checks quick/full path selection, 40 unique in-bounds board coordinates with alternating row direction, and four phase indicators. Passing these checks says nothing about the full original games. The collection itself has no app entry point.

Audit and publication boundaries

The read-only inventory covered seven source containers/files and 91 members: nine HTML members, five text documents and 77 raster-image members. Two HTML duplicates reduce the implementation count to seven. Static source inspection also counted 145 SVG and five WebP data-URI occurrences across those seven unique HTML implementations. No original image or other media is included here.

The board-quest originals can accept participant names, save player state and print named summaries. Egypt Arcade accepts team labels. France has YouTube destinations; Spain and Japan Compass have optional Google map/panorama routes. These source capabilities are documented and excluded from this reference collection. The original media were not decoded, their rights were not established, and external destinations were not loaded.

Original files remain unchanged. The review covered source structure, selected workflow functions, media references, input/storage/print/remote-access surfaces and exact duplicate detection. It was not a complete security, subject-matter or accessibility audit. No original app was executed, field-tested, certified or published during this preparation. Creator credit follows the user's confirmation; AI coding assistance is disclosed without claiming sole manual implementation.
