Classroom workflow reporting — synthetic demonstration

This small offline report shows how to describe operational work without publishing classroom records. It demonstrates completion rates, reporting coverage, validation and honest treatment of missing values. It was prepared in November 2026 for portfolio review; it is not a recovered production reporting system or evidence of measured school outcomes.

Every number is invented by deterministic arithmetic. The generator reads no student, staff or school records and does not sample, relabel, shuffle or fit historical data. Rows describe fictional preparation jobs across artificial periods, never individual learners. The separately supplied synthetic gradebook demonstrates an averaging workflow; neither example requires the historical classroom workbooks.

View and reproduce

Open report.html in a browser. It is a static file with no scripts, analytics, external assets, upload form or service connection. The complete generator, fixed-schema validation, invented fixture, tests and generated outputs are included in this project.

With an existing Python 3 installation, from a checkout of Zaliensen/classroom-workflows:

cd projects/classroom-data-reports
python3 -B verify_reproduction.py

On Windows, use py -3 -B verify_reproduction.py if the Python launcher is installed. Use a Python 3 interpreter; an older python command may select Python 2.

The verification command runs six unit tests, creates a fresh temporary folder containing only the two generator scripts, and compares the regenerated fixture, summary and report byte for byte with the included outputs. It does not change the project files. Only the Python standard library is used; no package installation, account or API key is required. Checks were run with Python 3.12.14.

To regenerate the included outputs deliberately, run these commands from the project folder:

python3 -B generate_demo_data.py
python3 -B build_report.py

The generator overwrites only its demonstration JSON; the report builder overwrites only the local HTML and summary JSON. Do not replace the fixture with real records.

How it works

generate_demo_data.py creates twelve period/workstream rows. build_report.py checks the fixed schema, allowed categories, uniqueness, count relationships and missingness rules, then produces report_summary.json and report.html. The report includes its denominators and a complete table so a reviewer can trace the result.

The fixture has 127 completed jobs out of 141 planned jobs in recorded rows (90.1%). Coverage is 10 recorded rows out of 11 applicable rows (90.9%). One applicable row is not recorded and one row is not applicable. A recorded zero remains in coverage. One duration is unknown, so 464 known minutes is an incomplete sum, not an estimate of total effort. These invented figures demonstrate calculations only.

Read DATA_DICTIONARY.md before interpreting the metrics. The fixed schema and validation are implemented in build_report.py; there is no external schema dependency. Six offline tests check arithmetic, denominators, missingness, schema rejection and deterministic output, followed by fresh reproduction; see VALIDATION.md.

Scope, provenance and limits

This newly written, AI-assisted portfolio example illustrates workflow analysis and communication. It is not a historical reporting system or evidence of deployment, use by colleagues or improved learning outcomes. No historical source code, learner records, IEP text, screenshots, institutional branding or third-party media were copied into it. No additional software license has been selected for this source.

The schema checks are data-quality controls, not a de-identification service: a future user could enter real information in an allowed numeric field or falsify a provenance declaration. The report must remain tied to its invented fixture. It has no student ranking, eligibility, placement, disciplinary or special-education decision function.

This is a synthetic portfolio demonstration. PRIVACY.md records the publication boundary and its references. Nothing here is a legal compliance certification or permission to publish historical records.
