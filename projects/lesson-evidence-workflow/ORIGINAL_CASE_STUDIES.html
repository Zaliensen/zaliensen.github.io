Return to Lesson Evidence Workflow

Recovered application case studies

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

These notes describe static source evidence from the actual Jungle Book and Mother Hen archives. They distinguish implemented code from tested behavior. They do not reproduce student records, original lesson content or media.

Jungle Book Studio

The source combines story presentation with vocabulary, comprehension, sequencing, spelling, reading and evidence-selection activities. Later script extensions add a precision workflow around the earlier activity engine.

conditions records level, question wording, choice count, response method, permitted support, model availability, picture support, spoken choices, word-bank use, response window and access mode. conditionSignature uses those fields for grouping. initialAnswer guards against overwriting an already captured first outcome, stores response timing and switches to confirmation. phaseFor selects initial, later or retention checks from earlier events. isValid asks for adult confirmation and excludes model exposure/answer-supplying help from its validity rule.

The backup validator checks schema, duplicate IDs, referenced learner profiles, score types, prompt codes, dates and several record limits. It preserves older backups without reading observations by adding an empty array. Workbook code generates separate first/final rates and leaves zero-denominator rates blank.

Practical value: the application attempts to preserve the circumstances behind a result instead of displaying only a final correctness count. Technical limits: layered scripts redefine or extend earlier behavior, and helper-level static inspection does not prove the complete UI calls the right rule in every route. The original also contains roster information, embedded name/lesson recordings, licensed-looking book illustrations and a microphone-related code path; none was brought into the demo.

Mother Hen Studio

The recovered package adds growth/evidence logic to a story-and-activity shell. Its code names initial checks, supported teaching, later checks, retention before reteaching, and transfer to another picture as separate phases.

independence returns an unknown value for older measurements, missing adult confirmation or practice. A first incorrect/no-response outcome cannot become independent solely because a later answer is correct. Printed models, answer-oriented adult/app help and peer exposure also affect the classification. AAC, activation assistance, neutral repeats and general access support are treated differently from answer help. stats groups completed eligible records by comparison/condition and date, while keeping omitted/unadministered records separately visible. The complete source also contains mastery thresholds and recommendations; those are unvalidated application rules and were deliberately excluded from this demo.

completeTrial records exposure from another turn's answer/feedback and from game practice. score records explicit adult confirmation and any answer-oriented prompt. The source separates in-memory task completion from the interpretation of the first response.

Practical value: this is an attempt to make a teacher's workflow and evidence assumptions explicit. Technical limits: the original needs integration tests for every route, careful review of legacy migrations and missingness, and domain review before real reporting. Some original helpers independently return an interpretation without checking all validity/status fields; the new demo adapter applies those guards first. No claim of validated assessment or causal learning gain is made.

Relationship to the other recovered work

Jungle Book and Mother Hen share 39 exact matching function declarations in the audited media-stripped source, including substantial data/summary/export helpers; retained demo functions were then re-extracted directly from the original HTML and hashed. These are good candidates for one shared architecture review with lesson-specific adapters.

Animal Habitats has a different visible surface: a large embedded content/data application with word playback, activity rotation and an appended learning extension. Chicken Life Cycle similarly has its own reading/voice and turn extensions. A direct exact-text function comparison between Mother Hen and the available Chicken logic index found no matches; formatting or different versions can explain that, so this is not proof of unrelated origin. Keep their provenance separate until a normalized comparison and functional review are complete.

The earlier Story App is a React/Vite source tree with story generation and gaze modules, rather than these exported monolithic lesson files. Its synthetic Story Studio portfolio demo remains a separately labelled reconstruction. None of these family relationships justifies merging private rosters or media into a common repository.
