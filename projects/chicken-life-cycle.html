Try the demonstration

Chicken life cycle — classroom workflow demonstration

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

A media-free reconstruction of a recovered classroom lesson: eight stages, short reading passages, word definitions, response choices, matching, scene building, letter building and sequence placement. Open index.html in a modern desktop browser. No package installation or account is required.

Why this project belongs in the portfolio

The recovered source contains an eight-page learning path and differentiated one/two/three-choice activities. It also includes teacher controls, reading support, learner tracking and embedded media. These structures make the application's design reviewable; classroom outcomes and production readiness have not been verified.

This public reconstruction demonstrates how a classroom workflow can be made inspectable: a teacher chooses the response complexity, a learner selects a response, placements require confirmation, feedback supports retries, and the next step waits for an explicit action. For a Deployment Strategist conversation, the useful connection is translating a user's workflow into concrete interaction choices and a demonstrable adaptation. This project does not establish Palantir platform experience or measurable adoption.

What changed for public review

  • Removed all original learner rosters, names, identifiers, class labels, goals, notes, name recordings and any existing learner state.
  • Removed every original embedded audio, image and video payload. Original media rights and identity safety were not established.
  • Wrote new short lesson text and simple inline SVG diagrams. No textbook pages, photographs, voices or other original media are included.
  • Reimplemented the learning interaction patterns in new JavaScript with AI assistance. This is an original-derived reconstruction, not the recovered application's untouched source.
  • Removed learner profiles, assessment histories, reports, downloads, imports, persistent browser storage and network access. Practice state exists only in the current tab and disappears on refresh.
  • Replaced audio-based help with visible definitions and text clues. This changes the access experience; it is not equivalent to the original narration or personalized support.

Try the workflow

  1. Read a stage and select a vocabulary word to reveal its meaning.
  2. Set response choices to one tap, two choices or three choices. One tap is participation only, never an accuracy result. Changing the setting restarts the current activity.
  3. Try a wrong choice, use the clue, then try again. The activity does not advance automatically.
  4. In Build a scene or Put it in order, choose a card and then confirm it in the highlighted place.
  5. In Build a word, choose letters in order. Show a clue separates the letters in the model.
  6. Complete an activity and select Next activity. You may also choose any stage or activity directly. Restart this demo clears the temporary practice state.

Use Tab / Shift+Tab to move through controls, Enter or Space to activate buttons, and arrow keys to change a select control. All interactions use native buttons and selects; no dragging is required. Visible focus, a skip link and live feedback are included. Screen-reader, switch-device and classroom usability testing remains outstanding. The text-and-diagram matching activity provides a visible word label with each diagram; it is not a picture-only assessment.

Verification and limits

node test_lesson.cjs checks 144 combinations (eight stages × six activities × three choice settings), including incorrect responses, explicit placement, completion locks, invalid inputs and fresh state. JavaScript syntax and public-file privacy checks are recorded in verification.json. These checks establish the tested behavior of the reconstruction only. They do not validate educational effectiveness, clinical suitability, legal compliance, accessibility conformance, or the recovered application's behavior.

This package contains no real learner records and provides no individual reporting or scoring system. The public reconstruction has not been field-tested. The original remains in private quarantine; private audit inventories are excluded from this repository. Creator attribution is based on Zachary Halaby's confirmation; it does not claim sole manual coding or verified classroom outcomes. Only the reviewed reconstruction and its documentation are published.

Files

  • index.html, styles.css, app.js: public demonstration interface and fresh SVG diagrams.
  • lesson.js: new lesson content and testable interaction state.
  • test_lesson.cjs: local behavioral checks using Node's built-in assertions.
  • verification.json: scoped verification results.

The repository has no dependency manifest, telemetry, remote assets, API keys or external services. No license for the recovered source or media is asserted by this preparation.
