Classroom engineering casebook

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

Source-backed explanations from ten selected Sent application candidates. This is a collection of engineering notes and six small retained functions, not ten restored public applications or ten additional repositories.

Explore the work

  • Pyramid of Ra — Reading adventure with map navigation.
  • Madrid Word Rescue — Dialogue, passage construction and activity transitions.
  • Madrid Arena — Quiz feedback connected to game progression.
  • Observation Mini Lesson — Shared lesson followed by rotating response turns.
  • Literacy Team Challenge — Multiple response modes with explicit tracing completion.
  • End-of-year Literacy Chase — Rotating response formats within a writing workflow.
  • End-of-year Literacy Adventure — Related literacy engine with different activity banks.
  • Letter Writing Mission — Scaffolded construction of a personal letter.

  • Food Mini Lesson — Vocabulary and a multi-select construction task.

The two end-of-year literacy themes share several exact event, turn, feedback and page-rendering functions. They are presented as related branches in one family. The other entries have distinct inspected state and interaction structures; shared subject matter alone does not make their code interchangeable.

Inspect the code

source-excerpts.cjs contains six exact function bodies from the selected files: map pathfinding, dialogue pacing, two activity selectors, a level-based writing selector and text chunking. New factory wrappers isolate dependencies and replace all participant state with fictional inputs. Run:

node test_excerpts.cjs

These checks exercise route boundaries, unreachable destinations, blocked-target fallback, pacing, task variation and chunking. They validate the extracted behavior, not the full games. PROVENANCE.json records source hashes and exact function hashes.

Portfolio positioning

Use one or two of these examples to explain how you translated a classroom workflow into state transitions, task choices and feedback. Lead with the tested, playable portfolio demonstrations; use this collection when a reviewer wants deeper implementation detail. No original names, rosters, signatures, responses, saved records, media files, base64 banks or remote resource links are distributed here.

The source descriptions were checked statically without executing the recovered apps. Actual teaching outcomes, production reliability and assistive-device testing require separate evidence. No public license for excluded original media is implied.
