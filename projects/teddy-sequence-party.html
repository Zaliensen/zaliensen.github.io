Teddy Sequence Party — sequence logic reference

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

The recovered application teaches first/next/last through timed routine scenes, prompted selection, review and ordering. Its timeline helpers use 18-second segments, then cycle among three steps during review. A separate task handler changes from touching a demonstrated step to checking or arranging the sequence.

Package status: inspected source reference, not a restored multimedia application. This package contains no original episode data, artwork, recordings or music. It retains selected logic and tests with an invented three-step routine.

Retained source and limitations

sequence-core.cjs retains the original segment, currentStep and promptFor function bodies. New wrappers provide explicit synthetic time/phase inputs and reject values outside the demonstration bounds. No original learner/session state is imported.

The source response handler rejects input while paused or after an item has been used, records correctness and highlights the target after an incorrect answer. That attempt record does not itself include a support flag, so this case study makes no independence-scoring claim. A future evaluation would need to distinguish hinted responses from unprompted ones.

This timed sequence workflow differs from Teddy Book Adventure's spelling, word-choice and placement task system. Static comparison found no exact function-body matches between the two reviewed files; they remain distinct workflow references within the classroom collection.
