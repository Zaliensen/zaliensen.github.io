Return to Classroom Reading Studio

Source and adaptation record

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance. Project ownership is confirmed by the creator.

Source family: recovered Face_Chapter_1_Chrome_Audio_Fixed.zip. Static inspection covered its HTML application, structure and media inventory without executing the original. The archive remains preserved separately, with its hash and detailed audit in private recovery records. No private local path is included here.

source-core.js retains the inspected escapeHtml implementation. The source getChoiceItems function is retained with the original global state dependency converted into an explicit parameter. A new wrapper rejects unsupported choice levels, invalid word positions and malformed tasks. The intended small-field/word-sequencing behavior is exercised across every new task fixture.

The interface, neutral word cards, session model and tests are newly prepared. Retry feedback, manual scan selection, word sequencing and teacher modeling follow the recovered interaction design. The source's response logging included a prompted flag; this reconstruction also makes supported completion visible and keeps it separate from any claim of independent performance.

The original HTML application and media directory are not included. All photographs, art, video, audio, book slides, character branding, personalized name/celebration clips, rosters, saved responses, media URLs, remote fallbacks, persistence, import and export functions are excluded. No source base64 payload is copied.

The reduction removes original media/phonics timing, sign-picture discrimination, larger lesson coverage, pointer dwell and detailed response reports. Those capabilities are documented as source findings, not represented as restored features. The neutral demo should not be substituted for supervised safety teaching. Third-party character, book and media rights are separate from ownership of the classroom workflow and remain outside this package.
