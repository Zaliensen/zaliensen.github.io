Return to Country Literacy Quests

Japan Quest — clean rebuild variant

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

An eight-lesson, 48-position board-quest variant with team turns, a 24-question early bank and ten declared literacy activities.

This is a documentation and code-reference entry, not a runnable classroom application. The full original HTML, media, participant fields, saved state and external-resource links remain outside this public package. Original files were inspected statically and preserved; the original apps were not executed.

The implementation supports discussion of workflow design and adaptation. It does not establish measured learning gains, verified deployment, adoption, Palantir platform experience, or sole manual coding. The cultural/subject content and accessibility behavior have not received a complete specialist or classroom review. No legal, accessibility or security certification is claimed.

Source-backed implementation evidence

  • LESSONS / getLessonList: Eight lesson objects; the quick path selects five fixed lesson indices (0, 2, 3, 5, 7).

  • QUIZZES_EARLY / QUIZZES_DEVELOPING: 24 early question records. The developing bank is a spread copy of that bank, not 24 additional distinct questions.

  • TOTAL_SPACES / LIFE_PATH_COORDS: 48 configured board positions; coordinates are data-driven rather than inferred from a screen image.

  • startTapCountMove / handleBoardSpaceTap: Stores pending movement and advances through tapped board spaces, making counting part of the turn workflow.

  • LITERACY_ARCADE_GAMES / startLiteracyArcade: Ten declared literacy-game configurations, separate from the six reward games dispatched by startArcade.

  • startFinalChallenge: Selects five early-bank questions and provides retry feedback before advancing.

Handling for public review

  • Name-entry controls are generated by initNameInputs/getEnteredNames; saved players, scores and printSummary can contain participant information. Those paths and values are not copied here.

  • The source has 28 SVG data-URI occurrences and browser speech synthesis; all media and voice code are excluded.

Family and version decision

Treat as a Japan curriculum/interaction variant of the shared board-quest engine. Do not count the engine again as an unrelated project.
