Egypt Arcade Mission — timed six-chapter activity

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

A separate chapter-based activity combining timed arcade rounds, short reading passages, questions and team progress.

This is a documentation and code-reference entry, not a runnable classroom application. The full original HTML, media, participant fields, saved state and external-resource links remain outside this public package. Original files were inspected statically and preserved; the original apps were not executed.

The implementation supports discussion of workflow design and adaptation. It does not establish measured learning gains, verified deployment, adoption, Palantir platform experience, or sole manual coding. The cultural/subject content and accessibility behavior have not received a complete specialist or classroom review. No legal, accessibility or security certification is claimed.

Source-backed implementation evidence

  • chapters: Six chapter objects. Each defines five image references, a story/passage and three questions: 18 question records in total.

  • startMission: Full and shorter modes initialize 40-minute or 25-minute mission clocks; per-arcade durations are 180 or 75 seconds. These are configured durations, not observed session lengths.

  • startArcadeEngine: Routes six game types: scanner, boat, catch, memory, letters and chase.

  • answerQuiz: Marks the chosen answer, reveals correction/help when needed and enables the explicit next-question control.

  • skipQuiz / nextChapterTeacher: Teacher routes can bypass the quiz or advance a chapter; a code/piece is recorded for progression.

  • clearGameTimers / state.paused: Timer cleanup and pause-state checks support controlled chapter transitions.

Handling for public review

  • The source accepts two team labels and maintains team scores. Public notes omit all user-entered labels and values.

  • The archive contains 33 JPEG files. They were inventoried but not decoded or copied; speech synthesis is also excluded. No remote HTTP host was found in the reviewed code.

Family and version decision

Different chapter schema, function set and timer/arcade engine from Egypt Quest. Keep as a distinct project inside this collection, not as another Egypt Quest release.
