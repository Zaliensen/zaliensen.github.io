Japan Red Sun Compass — guided mystery variant

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

A five-scene guided exploration flow emphasizing one visible clue, two questions, discussion and a collected piece.

This is a documentation and code-reference entry, not a runnable classroom application. The full original HTML, media, participant fields, saved state and external-resource links remain outside this public package. Original files were inspected statically and preserved; the original apps were not executed.

The implementation supports discussion of workflow design and adaptation. It does not establish measured learning gains, verified deployment, adoption, Palantir platform experience, or sole manual coding. The cultural/subject content and accessibility behavior have not received a complete specialist or classroom review. No legal, accessibility or security certification is claimed.

Source-backed implementation evidence

  • scenes: Five scene records with two question records each, for ten questions. Each scene stores three hotspot definitions.

  • renderExplore: The guided view deliberately renders only the first hotspot as one large clue. It exposes Show Me, picture/satellite controls and an explicit next action; three stored hotspots do not mean three active clues.

  • guidedSteps: Renders the four-stage Story → Look → Answer → Prize progress strip. A generic extract is included in the reference file.

  • openTalk: Opens a 30-second discussion prompt with a manual shared-completion action.

  • renderQuiz / renderPiece: Wrong-choice feedback allows another try; correct answers unlock a next-question route and the prize/piece screen.

  • renderExplore / teacherModal: The source has optional satellite-map/360 routes and teacher controls alongside the local picture workflow.

Handling for public review

  • No participant-name form or browser-storage token was found in the reviewed file. All source values remain outside the public package.

  • Five embedded WebP image occurrences and Google map/360 destinations are excluded. No media was decoded and no remote view was loaded.
