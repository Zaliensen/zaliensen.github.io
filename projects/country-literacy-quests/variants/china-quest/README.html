Return to Country Literacy Quests

China Quest — kindergarten literacy variant

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

An eight-lesson, 40-position board-quest variant with a 20-record early literacy question bank and ten declared literacy activities.

This is a documentation and code-reference entry, not a runnable classroom application. The full original HTML, media, participant fields, saved state and external-resource links remain outside this public package. Original files were inspected statically and preserved; the original apps were not executed.

The implementation supports discussion of workflow design and adaptation. It does not establish measured learning gains, verified deployment, adoption, Palantir platform experience, or sole manual coding. The cultural/subject content and accessibility behavior have not received a complete specialist or classroom review. No legal, accessibility or security certification is claimed.

Source-backed implementation evidence

  • LESSONS / getLessonList: Eight lesson records and a five-record quick lesson path.

  • QUIZZES_EARLY: 20 question records with picture/symbol, cue and answer metadata; the first inspected record has two choices. This is source structure, not a reading-level validation.

  • QUIZZES_DEVELOPING: A spread copy of the early question bank; it is not a separate set of additional questions.

  • LIFE_PATH_COORDS / createBoardSpaces: Forty configured board positions; this version uses movePlayer rather than the later tapped-count movement functions.

  • LITERACY_ARCADE_GAMES / startLiteracyArcade: Ten declared literacy activity configurations.

  • startQuiz / startSentenceChallenge / makeSequenceRound: Separate quiz, sentence-building and sequence-round functions support multiple response patterns.

Handling for public review

  • The shared setup/save/print architecture can process participant names and points. No input values or saved learner state are included.

  • The source includes 27 SVG data-URI occurrences and device-voice code; both are excluded.

Family and version decision

Retain as a curriculum/access adaptation within the shared board-quest family, not as an unrelated software engine.
