Spain Detective Mission — guided landmark exploration

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

A separate six-chapter clue-finding and question workflow with local views and optional online panorama destinations.

This is a documentation and code-reference entry, not a runnable classroom application. The full original HTML, media, participant fields, saved state and external-resource links remain outside this public package. Original files were inspected statically and preserved; the original apps were not executed.

The implementation supports discussion of workflow design and adaptation. It does not establish measured learning gains, verified deployment, adoption, Palantir platform experience, or sole manual coding. The cultural/subject content and accessibility behavior have not received a complete specialist or classroom review. No legal, accessibility or security certification is claimed.

Source-backed implementation evidence

  • CHAPTERS: Six chapter records with 27 view entries in total (6, 5, 4, 4, 4, 4) and two questions each, for 12 question records.

  • findClue: A one-time clue action marks the hotspot found, increments progress and enables the next-view button.

  • answer / nextQuestion: An answered guard prevents repeated scoring/action, shows correct/retry feedback and allows explicit continuation.

  • finishChapter: Collects one chapter tile and moves to a travel/share screen before the next chapter.

  • openPano / openOnline360: Local panorama UI retains a regular-view route; a separate user action opens an external destination.

  • CREDITS / buildCredits: 17 source-credit records are present. Their presence is not a completed rights review.

Handling for public review

  • No name-entry form or persistent browser-storage token was found in this reviewed HTML; this is a scoped static observation, not a guarantee about other versions.

  • The archive includes 37 JPEG and seven PNG files. Optional Google destinations and Wikimedia credit links are present; images, URLs and original application code are excluded.

Family and version decision

Shares a detective/clue theme with Japan Compass, but has a different six-chapter/view engine and function set. Retain as a distinct implementation without claiming independent development history.
