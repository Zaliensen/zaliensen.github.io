France Quest — ten-arcade / YouTube variant

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

An eight-lesson, 40-position board-quest variant with a larger arcade dispatcher and optional external song links.

This is a documentation and code-reference entry, not a runnable classroom application. The full original HTML, media, participant fields, saved state and external-resource links remain outside this public package. Original files were inspected statically and preserved; the original apps were not executed.

The implementation supports discussion of workflow design and adaptation. It does not establish measured learning gains, verified deployment, adoption, Palantir platform experience, or sole manual coding. The cultural/subject content and accessibility behavior have not received a complete specialist or classroom review. No legal, accessibility or security certification is claimed.

Source-backed implementation evidence

  • LESSONS / getLessonList: Eight lesson records, with the shared five-lesson quick path.

  • QUIZZES_EARLY / QUIZZES_DEVELOPING: 20 early records. The developing declaration contains eight added records plus a spread of the 20 early records, for 28 total entries.

  • boardCoordinates: A serpentine five-row by eight-column board layout with small wave/tilt offsets; a generic extract is included in the reference file.

  • ARCADE_GAMES / startArcade: Ten dispatched arcade functions: catching, popping, flight, river navigation, market matching, macaron matching, Louvre memory, cycling/slalom, perfume garden and chateau doors.

  • YOUTUBE_SONGS / nextYouTubeSong / startSongSpace: Six song metadata entries and a rotating song queue; the source constructs YouTube links.

  • animateDieAcrossBoard / printSummary: Animated dice movement and the shared participant-summary print path are present.

Handling for public review

  • Name inputs, persistent game state and participant printouts are excluded.

  • 43 SVG data-URI occurrences, speech synthesis and YouTube destinations are excluded. No external video was loaded or evaluated.

Family and version decision

START and Editable Source HTML members are byte-identical. This is the France variant of the reusable board-quest engine, with a different arcade/song feature set.
