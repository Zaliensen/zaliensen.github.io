World Literacy Board Game

Classroom activities are used on a Smartboard; keyboard controls are an unused backup. Browser/pointer checks are reported separately from physical-device validation.

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

A classroom board game that connects a physical-looking path, counted movement and short literacy activities. This review edition retains the actual V15 board and activity engine. The initial November 26 preparation retained 39 of 48 named functions unchanged; later bonus-turn fixes are recorded separately in the provenance notes. Edits replace media and names, remove external video launching, improve access and correct specific state transitions.

Open index.html with its assets directory alongside it. No installation, server or internet connection is required. The twelve players are fixed fictional labels. No personal names can be entered through setup, and no learner record is saved or exported.

Workflow and adaptations

Select one of five country contexts, one of three task settings, and 24, 32 or 40 board spaces. Roll the die and activate each highlighted space to count the movement. Landing selects a matching, question, spelling, fact, stamp, bonus or arcade activity. Many activity routes require an explicit Continue after success.

The settings change actual task demands: the smaller field uses fewer answer options; other settings add distractor letters or short reading questions. These inherited labels describe configured behavior, not verified grade suitability. Team points support the game and are not an assessment of individual ability.

The board and activity sequence are useful examples of translating a teacher-led routine into an interface: visible turn ownership, discrete movement, retries, feedback and a clear handoff to the next player.

Source preservation and cleanup

The reviewed archive is World_Literacy_Board_Game_V15_Map_Path.zip, attached to Sent Items on July 29, 2026. Original bytes were preserved and inspected without running them. The ZIP passed traversal, symlink, encryption, bounded-size and CRC checks.

All 28 original image assets were excluded. The review edition supplies 30 new SVG files: country labels, illustrative backgrounds and word cards. Consequently, picture matching and the picture arcade now use printed words. This does not reproduce the original photographic discrimination experience. The background is illustrative, not a geographic map.

All twelve original name defaults were replaced with Player 1 through Player 12. Their setup fields are read-only, and saving ignores name values. Original external video URLs were removed; those spaces now offer a teacher-led offline pause. Sound and procedural music start off.

Targeted fixes make repeated passport activation award only once, prevent movement beyond a pending landing, and prevent the arcade from presenting the target item as a supposedly wrong choice. The stamp is now a native button. Space on an existing button or input retains native keyboard behavior. Focus visibility, label sizing and player-list layout were improved.

The November 27 update fixes a bonus space that previously scheduled two turn advances and skipped a player. Celebration completion now owns one advance, and dice input waits until that handoff. Opening settings settles an awarded bonus turn once; canceling settings preserves that next player. Saving settings resets to the first player and invalidates any old celebration callback.

Verification and limits

Nine browser scenarios passed, including all 45 country/task-setting/board-length combinations, wrong-then-correct matching, repeated stamp activation, pending movement, keyboard behavior, arcade distractors and the offline pause. No external requests or page errors occurred. See VALIDATION.md and PROVENANCE.json.

Run the bonus/settings regression checks from this folder with node test_game.cjs. Six scenarios use the public functions with simulated DOM/timers, including an already-queued callback after cancellation. These checks reproduced the double turn before the fix and pass after it; they do not replace real touch-device testing.

This retains a large-board layout intended for classroom displays. It is not a mobile-first redesign. The arcade still has a short timer and moving targets; it is an optional game route, not a validated accessible assessment. Some modals, speech output, touch boards and assistive devices need further testing. Cultural lesson statements and inherited task labels were preserved as source content, not independently evaluated for curriculum use.

Keep this as one board-game family with country data variants, rather than five separate repositories. The source demonstrates implementation and adaptation; classroom outcomes are not established. See LICENSE_STATUS.md before public source redistribution.
