Prediction research and deterministic decision support

Publication scope

This is a documentation-only portfolio entry. The source package, configuration files and any local commands described below refer to privately reviewed material; that package is not currently distributed from this page. The notes describe the prototype and its limits, not a publicly reproducible deployment.

An offline extract from a larger Python research and operator-dashboard project. It demonstrates transparent calculations and missing-data behavior using synthetic inputs. This review package cannot connect to an exchange or place orders.

Problem and intended user

An operator comparing market observations needs to distinguish price, available depth and capital exposure without hiding calculations behind generated prose. The broader project collects and normalizes observations, records data-quality states, ranks research items and exposes an operator interface.

Included code

  • pricing.py: decimal conversion, complementary probabilities, midpoint and divergence.
  • capital.py: model calculations for a filled bid and two-sided quote reserve.
  • bundles.py: executable price/size summaries and depth coverage.
  • demo.py: a new deterministic synthetic demonstration.
  • tests/test_pricing_capital.py: recovered tests retained as evidence; pytest required.
  • tests/test_offline.py: new standard-library regression checks.

The three calculation modules are retained byte-for-byte. Their formulas are model assumptions, not a certified risk system. This is a selected extract rather than the complete application.

Architecture and source history

The larger source tree uses Python, FastAPI, Pydantic and SQLite, separating collectors, normalization, deterministic engines, persistence and presentation. Later revisions contain execution and recovery code. The old top-level README says advisory-only and is inconsistent with that later source. This README describes the staged extract and does not repeat that outdated whole-system claim.

Run the offline example

Use Python 3.10 or newer from this directory:

python demo.py
python -m unittest discover -s tests -p test_offline.py -v

No account, API key, package installation, database or network connection is needed. The retained pytest file can be inspected or used in an existing trusted pytest environment; it was not the validation command for this package.

Demonstrated behavior and limits

The demo shows reproducible arithmetic, complementary outcome prices, rejection of crossed midpoints and explicit unknown depth. Regression checks exercise these paths against fixed expected results. They do not prove live integrations, profitability, reliability or deployment outcomes.

Contribution and provenance

The source was recovered from a local project associated with this portfolio. The precise division of specification, implementation, review and AI assistance still needs the owner's confirmation. This package and its new demo/test were prepared with an AI coding assistant in November 2026. Historical source is not represented as newly authored work.

Excluded material

Credentials, account data, reports, database snapshots, notifications, private configuration, exchange collectors, live execution/recovery workers and service launchers are excluded. Original local files are preserved. No source license was identified for this extract; publication and licensing remain subject to ownership review.

Design discussion

Useful discussion topics include separating deterministic calculations from generated research, preserving unknown data, surfacing source provenance to operators and keeping documentation aligned with implementation. A next improvement is a fully specified non-finite and negative-input contract across the calculation functions, followed by property-based tests. The extract retains existing formulas so the historical behavior remains inspectable.
