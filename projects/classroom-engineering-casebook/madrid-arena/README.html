Madrid Arena

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

Quiz feedback connected to game progression. The source connects exploration, quizzes, upgrades and a canvas arena through explicit stages. It is distinct from Madrid Word Rescue's dialogue-and-passage workflow.

How the code implements the workflow

Function or component Implemented behavior
showStage / completeStage Manage progression between the setup, exploration, game and quiz views.
answerQuiz Prevents repeated scoring after the quiz is marked answered; incorrect answers disable choices and expose a hint.
renderUpgradeRack / awardUpgrade Connect quiz progression to visible upgrades.

Implementation decisions

answerQuiz checks a completion flag before changing the score. A correct answer awards an upgrade and enables progression; an incorrect answer disables that choice and reveals a hint. If only one option remains, the source marks it correct and awards a smaller reward. The distinction matters when interpreting game state: reaching the next stage can follow elimination as well as an initially correct choice.

Included and excluded

Documentation only. The source can also award a lower reward when only one option remains; that behavior must not be described as an independent correct answer. Media, saved state and the full game are excluded.
