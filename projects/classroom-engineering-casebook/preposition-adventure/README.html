Preposition Adventure

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

Adjustable spatial-language response formats. The source chooses among recognition, placement, sentence construction, sorting, tracing and explanation activities. It tracks the last selected activity for a participant and the last activity across the session.

How the code implements the workflow

Function or component Implemented behavior
activityFor Uses different activity pools and attempts to avoid both the current participant's last activity and the globally previous one.
prepOptionsForStudent Reduces the response set to two choices for one configured level.
enableSimpleDrag / handleDropZone Separate input handling from response interpretation.
