Literacy Team Challenge

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

Multiple response modes with explicit tracing completion. The source combines team turns, question history, choice, placement, tracing and coloring. Its later tracing version separates drawing, completion and continuing.

How the code implements the workflow

Function or component Implemented behavior
pickQuestion Uses per-participant question history and a recent-question list to reduce repetition.
renderTrace Enables Finish Tracing after a drawing movement; a separate Continue button advances after completion.
renderChoices / renderDrag / renderColor Implement different response formats within the same activity shell.

Implementation decisions

The tracing screen separates input, completion and progression. A drawing movement enables Finish Tracing; that button records completion and reveals Continue, which advances the activity. Clear resets the drawing and both controls. This makes progression explicit, but the completion event records participation in the drawing interaction: it does not check the shape, coverage or accuracy of the traced letters.

Included and excluded

Documentation only. Learner names, question-history records, remote media and the full app are excluded. Any drawing movement can unlock completion; the source does not verify letter shape or handwriting accuracy.
