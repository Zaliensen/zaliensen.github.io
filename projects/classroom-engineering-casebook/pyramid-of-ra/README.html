Pyramid of Ra

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

Reading adventure with map navigation. The source combines tile-map exploration, passages, questions, support choices, encounters and saved progression. It is a distinct game architecture rather than a reskin of the classroom turn-based activities.

How the code implements the workflow

Function or component Implemented behavior
findPath Uses a queue, visited set and predecessor map to find a walkable four-direction route. A blocked destination falls back to a nearby walkable tile.
useQuestionSupport Provides highlighting, word banks, elimination and hints; increments a support-use counter.
saveGame / repairState Separate persistence and state repair from the map renderer.

Implementation decisions

findPath searches four-direction neighbors with a queue and visited set, then reconstructs the route through predecessor entries. Before searching, a blocked destination is replaced by an adjacent walkable tile when one is available. The function returns an empty route when the chosen destination cannot be reached. Keeping this calculation separate from rendering makes map movement inspectable with small synthetic grids.

Included and excluded

The generic pathfinding function is retained in the tested excerpt module. The complete game, art, passages, save files and personalized state are excluded. Support-use counts are software events, not evidence of learning.

Static inspection and JavaScript parsing were performed on the recovered source without launching it. Only the generic excerpts identified in the collection's provenance file are runnable here. The original full application has not been runtime-tested in this review. Any future complete public release needs a separate source and media review.
