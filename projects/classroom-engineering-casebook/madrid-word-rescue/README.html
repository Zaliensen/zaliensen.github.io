Madrid Word Rescue

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

Dialogue, passage construction and activity transitions. The source advances through dialogue, sentence selection, a constructed passage and several canvas mini-games. It has separate scene, input and rendering functions.

How the code implements the workflow

Function or component Implemented behavior
dialogueDelayFor Computes a minimum reading delay of 2.5 seconds, increasing with word count.
checkDialogueChoice Locks answer controls, shows an explanation, and provides either an explicit retry or a button to build the passage.
startMiniGame / gameLoop Separate activity setup from ongoing canvas updates.

Implementation decisions

dialogueDelayFor scales the display delay with word count while imposing a 2.5-second minimum. Answer handling is a separate decision: checkDialogueChoice disables the choices before displaying an explanation, then offers either a retry or an explicit button to build the passage. Timing controls presentation pace; the choice and transition controls determine when the workflow moves forward.

Included and excluded

The timing helper is retained and tested. The full dialogue, characters, recordings, media, stored records and original application are excluded. A timed reading delay is a design choice, not measured comprehension.

Static inspection and JavaScript parsing were performed on the recovered source without launching it. Only the generic excerpts identified in the collection's provenance file are runnable here. The original full application has not been runtime-tested in this review. Any future complete public release needs a separate source and media review.
