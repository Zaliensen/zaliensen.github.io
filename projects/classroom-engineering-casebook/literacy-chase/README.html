End-of-year Literacy Chase

Creator and classroom workflow designer: Zachary Halaby. Developed and iterated with AI coding assistance.

Rotating response formats within a writing workflow. The source selects different activities by configured level and turn, then brings the work into a page/signature workflow. It belongs with the related end-of-year literacy family rather than a separate repository for each character theme.

How the code implements the workflow

Function or component Implemented behavior
pickMode Rotates through level-specific response modes and tries to avoid repeating the previous mode.
renderChunkBuilder / renderWordBuilder Break written responses into selectable construction steps.
renderAllPages / exportData Generate artifacts from session work in the original application.

Implementation decisions

pickMode uses a configured activity pool, rotates it by stop and participant indexes, and tries to avoid the previously selected format. The response renderer can therefore switch between choices, sentence frames, construction steps and open text without replacing the surrounding turn workflow. The retained selector isolates this routing decision from the original page generation, signatures and exports.

Included and excluded

The generic mode selector is retained with isolated in-memory state and tested using fictional inputs. Original characters, videos, learner plans, signatures, text responses and export records are excluded.

Static inspection and JavaScript parsing were performed on the recovered source without launching it. Only the generic excerpts identified in the collection's provenance file are runnable here. The original full application has not been runtime-tested in this review. Any future complete public release needs a separate source and media review.
