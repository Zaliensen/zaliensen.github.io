Validation

Checked again on 2026-11-27 using Python 3.12.14 and the standard library. No real classroom file was opened or imported for this example, and no network service was called by the generator, report builder or tests. Earlier independent review checked the arithmetic and missingness definitions.

Commands completed successfully:

python3 -B verify_reproduction.py

On Windows with the Python launcher, use py -3 -B verify_reproduction.py. The check runs the following six unit tests and then regenerates the three outputs in a fresh temporary folder containing only the two generator scripts. The generated data, summary and HTML must match the included files byte for byte.

Six tests passed:

  1. Reporting coverage distinguishes unrecorded and inapplicable rows.
  2. Fixed totals independently check 127 completed / 141 planned jobs, 464 known minutes, the recorded zero and the unknown duration.
  3. Zero denominators return no rate and render an explicit explanation.
  4. An extra identity field and a false synthetic declaration are rejected. The test marker is invented.
  5. Negative counts, booleans used as counts, impossible count relationships, duplicate keys and replacing a missing count with zero are rejected.
  6. Fixture generation is deterministic and report output has no scripts, input form or remote assets. Its sole external hyperlink points to this source package; it loads only when followed.

Fresh reproduction also passed for data/synthetic_operations.json, report_summary.json and report.html. Outputs are written as UTF-8 with LF line endings, and the project attributes preserve those endings on checkout. The expected figures are 127 completed / 141 planned jobs (90.1%), 10 recorded / 11 applicable rows (90.9%), 464 known minutes and one recorded row with unknown duration. The known zero remains in reporting coverage. These are invented arithmetic examples, not real outcomes.

These tests validate the intended sample behavior. They do not test a production deployment, certify accessibility or prove arbitrary data have been de-identified. The fixed HTML includes table captions, column headers and overflow handling; it has no interactive application runtime.
